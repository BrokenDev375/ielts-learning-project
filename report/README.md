# Báo cáo bài tập lớn

Báo cáo cuối chưa được viết trong bước khởi tạo module 1.

Khi làm báo cáo, theo mục 8 INSTRUCTION.md: Title, Abstract, Keywords, Introduction, Background/Related Work, Problem Definition, Proposed Approach, System Architecture, Network Communication Design, Implementation, Experimental Setup, Results, Discussion, Novelty/Contributions, Limitations, Future Work, Conclusion, References, Appendix.

Nguồn triển khai: source/common/API.md, statics/architecture.mmd, statics/protocol.mmd. Số liệu phải lấy từ test/experiment thực tế, không lấy ví dụ format làm kết quả.

Submission.md ở thư mục LTM quy định báo cáo nên là .docx và tên NhomXX_TenProject_Report.docx; đặt nhóm/tên cuối khi có thông tin. Chưa tạo report.pdf rỗng hoặc báo cáo hoàn chỉnh giả.
